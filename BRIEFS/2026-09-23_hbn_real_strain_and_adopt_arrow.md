## The law to build

1. THE HBN IS THE REAL STRAIN. A batch minted from METRC's name (`mintMetrcBatch`) carries `strain_id` = the live strain whose `hbn_code` is the HBN's fourth segment (`mint.strain_code`, three digits as `parseHbn` reads them), and `market_strain` = METRC's strain name (the item's strain, as `adoptStrain` reads it) through `inheritMarketStrain(metrcName, realStrain.name)`, so a blank METRC name inherits the real strain's own name (canon 0.30.9). An adoption never mints, renames or matches a strain by name: `strainForMetrcBatch` goes. No live strain carrying that code: refuse in words naming the HBN and the code and where the strain is added (`{hbn} cannot be adopted: no strain carries code {code}; add it in Admin, Lookups, Strains.`), nothing minted, nothing inserted. Two or more live strains carrying the code (`strains.hbn_code` is not unique): refuse in words naming the code and the strains (`{hbn} cannot be adopted: code {code} belongs to {strains}; fix the codes in Admin, Lookups, Strains.`), nothing minted.
