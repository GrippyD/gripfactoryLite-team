## 2. Phase B: the client (Laws 3, 4, 5)

- **Law 3, the host guard.** `SANDBOX_BASE_RE = ^https://sandbox-api-[a-z]{2}\.metrc\.com$` and `PRODUCTION_BASE_RE = ^https://api-[a-z]{2}\.metrc\.com$` tested against `metrcBase(env)` (the parsed origin), never the raw var. `metrcHostKind` names sandbox, production or other. A GET on an "other" host makes no fetch, records nothing and attaches no key. New `metrcUrl` refuses any URL whose origin is not the base before a key is attached (an absolute, protocol-relative or backslashed path can no longer leave the Metrc origin). `metrcSend` (POST, PUT, DELETE; no caller yet) is refused on production always, on sandbox unless `METRC_EVAL_ENABLED` is exactly "true", on other always. `resolveSweepMode` gives `write` only on a production host; `write` on a sandbox host resolves to `dry_run` with plain words; blank or unknown is `off`. `METRC_WRITE_ENABLED` stays `false`, `testingPostRequest` stays null, and `METRC_EVAL_ENABLED` is not in `wrangler.toml`. Both doors send `redirect: "manual"`; a 3xx is a failure (a write body is never re-sent to a redirect target).
- **Law 4, keys.** `userKeyFor(env, license)` returns the single `METRC_USER_KEY` for every license (the docs tie the key to the user); `METRC_USER_KEYS` is never read (one test proves it). `scrubKeys` now removes the raw keys, the base64 token and the "Basic <token>" form; a key the Basic header cannot carry is refused in plain words instead of throwing inside the catch. `callPath` drops every key-bearing query parameter from the logged path, so a `userKey=` never reaches `metrc_api_calls`.
- **Retry-After.** A blank or missing header waits 1,000 ms (it waited 0 ms: `Number("")`), a number waits that many seconds capped at 10,000 ms, a date or text waits 1,000 ms. The lab sweep's `readPaged` keeps its throw (Law 5).
- **Law 5, the pager.** Page size 50 from `metrc_page_size`, clamped to 1..50, always sent with `pageNumber`; envelope and bare-array bodies; a page ceiling of 4,000 that records "ceiling" and re-dues the pass, never a silent stop; tagged results ok, refused, rate_limited (second 429 or Retry-After above the cap ends the scope and saves the cursor; other licenses continue), failed (scrubbed), host_refused. Windows in UTC seconds, overlap `metrc_window_overlap_minutes` (5), chunk `metrc_window_max_minutes` (1440), oldest first; the high-water mark moves only after every page of a window; a tick that runs out mid-window resumes at `win_page`; a window at the ceiling is halved down to a floor. Cursors per (host, license, endpoint, mode) in `metrc_cursors`; a dry_run cursor never moves a write cursor; an empty write cursor needs a full pass first; each run saves only its own columns (an interleaved full pass and incremental cannot resurrect a finished pass or clobber `gone_override`); a soft-deleted cursor cannot make the scope throw (partial unique index `WHERE deleted_at IS NULL`). Full passes store each page's tags in `metrc_pass_pages` and return the seen set on completion; `full_due_at` is the pass start plus the cadence. Budget: `metrc_tick_calls` (60), `metrc_tick_license_calls` (20), `metrc_tick_wall_ms` (240000), `metrc_tick_rows` (3000), a D1 cap of 700 queries per tick (a code constant, A27), and the month pace `metrc_month_calls` (45,000) computed per tick as the smaller of the tick budget and the month's remainder over the ticks left, never below one call per scope; a dropped pass (ceiling or short) is due again at now plus the cadence, not its start plus the cadence, so a long pass never restarts at once; `needsFullPass` waits for that due time even on a cursor with no mark (ruled as the fix pass built it). D1 queries are counted one per statement, batches included (the conservative reading); whether D1 counts a batch as one query or N is UNRESOLVED (appendix d section 2), and at N the 700 cap holds about 54 calls a tick (appendix d section 3).
- **Migration 0096.** `metrc_cursors`, `metrc_pass_pages`, `metrc_facilities` (host, license_value, in_lookup, reached, can_grow_plants, can_record_processing_jobs, can_track_vegetative_plants, license_type, checked_at; never EmployeeLicenseNumber or FacilityId), `ALTER TABLE metrc_mounts ADD COLUMN source TEXT NOT NULL DEFAULT 'file'`, and the 17 `app_config` seeds as `INSERT OR IGNORE` in the 0088 shape.
- **Test connection per license (A22, A33).** Still one `GET /facilities/v2`; the response's `License.Number` values are matched case-insensitively against the active lookup licenses and written to `metrc_facilities` for the current host; the page shows, per lookup license, "Reached by this key", "Not reached by this key" or "Not checked yet", plus the count of other facilities the key reaches, each element with a native `title` help naming `Admin\Data Lookups\Logistics\Licenses`; the flash reads "Connected. {n} facilities. {r} of {k} licenses reached."
