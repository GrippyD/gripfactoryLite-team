## What landed

The KPI detail change log names the period, the dim (Total or the farm code), and the person's display name, joined in the same batch. History labels each value with its dim.

The detail gains the live targets, a void per row, and an add form (`data-dd-target`, `data-dd-target-form`). `POST /admin/director/kpi/:key/target` inserts the row and logs each non blank field through `logsForInsert`. A second live row on the same key, dim, period kind, and effective date is refused in words. `POST /admin/director/target/:id/void` sets deleted_at and logs that one field. Blank phasing keeps the target as entered. `flat` or a weight list is an annual number: `flat` divides by 12 or 52, weights are stored as shares summing to 1, and phasing on a day, quarter, or season is refused. Week 53 uses the 52nd share. `dd_phasing` is not read.

`ddAllowedDimKeys` is the one list: blank, plus PNN, ARL, and PNS when dims include farm. The grid, the target dim select, and the import validator use it. Period kinds are the period words, never cadence words.

The wall goal line, in the same batch, fills from the total's target in force where the snapshot goal is still blank. goal_ref and goal_direction are unchanged. The home card counts still follow the snapshot goal.

`GET /admin/director/questions` is one batch: 17 cards, the config value, and the KPI titles named by kpi_keys. `POST /admin/director/questions/:key/rule` validates with `DD_CONFIG_RULES`, writes nothing when the value is unchanged, and otherwise updates app_config, marks the question ruled, bumps def_version on every kpi_keys member (one statement, one log each), and supersedes live non-hand values in open periods of that cadence. Hand rows are left alone.

`GET /admin/director/import` has Values and Targets forms. Preview parses with `parseCsv`, lists every row error, and offers Commit only when the file is clean. Commit re-validates and writes in batches of at most 50 statements. A values row equal to the live hand value is skipped. A values file with a note column is refused. The home links to Questions and Import. ADMIN_GROUPS was not changed. `/admin/director/questions` and `/admin/director/import` are registered before `/:dept`.
