## A formula

A text box, memo, barcode, or QR whose content starts with `=` is a formula. Anything else is still text with `{tokens}`, the same as L2.

The grammar follows Excel: `NAME(arg, ...)`, names in any case, text in double quotes (`""` is one quote), whole and decimal numbers, `{key}` and `{d:table:column}`, `&` to join text, and calls inside calls. Square brackets name a catalog field by its key, by its words, or with dots and spaces as separators, case ignored. `[package_tag]`, `[Package tag]`, and `[PACKAGE.TAG.ID]` are all `{package_tag}`. A name that matches no field is an error that names it. A catalog field or a `{d:table:column}` token that has no value is blank.

Functions: `LEFT`, `RIGHT` (the count defaults to 1; 0 is blank; past the end returns the whole text), `MID` (start counts from 1), `LEN`, `UPPER`, `LOWER`, `TRIM` (ends and doubled spaces), `SUBSTITUTE` (every match), `CONCAT`, `IFBLANK`, and `TEXT`. Date formats use `YYYY YY MMMM MMM MM M DD D`, separators kept as typed. `"MM/DD/YY"` on `2026-09-24` is `09/24/26`. `"MMM D, YYYY"` is `Sep 24, 2026`. Number formats are `0`, `0.0`, `0.00`, `0.000`, and `#,##0`, rounded half up. A date that is not a real date, or a number format on text that is not a number, comes back unchanged. Month words are English. The result is capped at 500 characters.

`evaluateFormula` in `src/labelformula.ts` returns `{ value, error, errorKey, errorVars }` and does not throw. `bindText` calls it when the content starts with `=`, so the editor's server render and every print page use it. The editor's client runs that same function: `formulaEngineSource()` is the function's own source, wrapped so the worker's `__name` helper exists in the page. One table of cases runs through the module and through that client copy.

A formula that does not parse, names an unknown function or field, or has the wrong arguments shows `#ERROR` on the object. The options pane says why, in English or Spanish. Save Template refuses while any object holds a broken formula, and the refusal names the object. At print, a blank field does not error: `RIGHT` of blank is blank. A barcode or QR encodes the result. Toggle caption shows the result. Attach shows the attached object's result, not its formula.

`layoutTokens` reads fields inside formulas, both `{key}` and `[field]`, so Quick Print still warns when a bound field is blank.

Source Data and Connections insert `{key}` at the cursor when the content is a formula, and still append when it is not. Under the content box, Formulas opens a short list: each function with one example from the catalog, including `=RIGHT({package_tag},6)`. Preview with package shows the results.

The editor also carries ink and fill on text, memos, codes, and shapes, bring to front and send to back, and a refusal when a barcode or QR is white with no fill. Those checks are in the editor tests and in the smoke.
