## A package ID

24 characters after trim and upper case: `1A4`, then 16 facility characters, then a 5 digit numeric tail. A short ID, a prefix other than `1A4`, or a tail that is not five digits is refused in words. Lower case is accepted and stored upper case. On `db_backups/20261004-085455_pre_l2`, all 12,759 mirror tags are 24 characters, start with `1A4`, and end in five digits.

An ID the app does not know (not in `metrc_packages`, and not on a live `local_inventory_items` row) is allowed. The preview says its fields will print blank. The package tag on the label is still the ID that was typed. Looked-up fields print blank.

## The run

Without roll, every container is the one package. The run is Container Qty times Labels per container. With roll, container n (from 0) keeps the facility characters and adds n to the numeric tail, the same five digits, leading zeros kept. A tail that would need a sixth digit is refused in words (`99999` plus 1). Each container's labels fill from that container's own package through L2's resolvers.

The preview lists every container's ID, its item and strain, an unknown ID, and any bound field that resolved blank. Print and Back are on that page. Back refills the form.

## The print
